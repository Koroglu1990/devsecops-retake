# Пересдача DevSecOps · интерактивный практикум ITHUB

Практикум для пересдачи по двум дисциплинам:

- **391.ВДО.25О Введение в DevSecOps** — список 1, 7 студентов, 10 частей, 36 заданий;
- **3171.ДОС.26В DevSecOps** — список 2, 11 студентов, 11 частей, 37 заданий.

Студент выбирает дисциплину и свою фамилию. У каждого студента своя предметная область (KinoStream, FoodRush, StockFlow и т. д.) и свои числа в расчётных заданиях.

## Структура

```
index.html          разметка страницы
css/style.css       оформление
js/config.js        настройки: адрес сайта, Google Форма для отчётов
js/roster.js        списки студентов по дисциплинам
js/engine.js        логика практикума, проверка, отчёты
js/data/sNN.js      задания каждого студента (закодированы, ответы хранятся только в виде хешей)
```

## Публикация на GitHub Pages

1. Создайте репозиторий, например `devsecops-retake`, и загрузите в него **содержимое** этой папки (index.html должен лежать в корне репозитория).
2. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты практикум откроется по адресу `https://koroglu1990.github.io/devsecops-retake/`.

Если практикум открыт с другого адреса или локально, в отчёте появится пометка «ИЗМЕНЁННАЯ КОПИЯ». Адрес меняется в `js/config.js` (`EXPECTED_HOST`).

## Отчёты

По завершении отчёт автоматически уходит в Google Форму из `js/config.js`. В поле «Группа» записывается «Пересдача <код дисциплины>», в поле «Статус» — предметная область, время, число ошибок и флаги подозрительной вставки или изменения кода проверки. Чтобы собирать пересдачу в отдельную таблицу, создайте новую форму с теми же четырьмя полями и замените `GOOGLE_FORM_ACTION` и номера `entry.*`.
